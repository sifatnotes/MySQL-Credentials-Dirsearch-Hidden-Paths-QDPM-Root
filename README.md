## Learning Path

A practical progression through these **cybersecurity labs**:

1. Start with **Credential Cache** and **Base64 Vault Break** for basic information and encoding analysis.
2. Explore **Table Hunt** and the MySQL-focused labs.
3. Move into **Hidden Config Hunt**, **Robots and Secrets**, and **Hidden Paths**.
4. Practice directory discovery with **Dirsearch Deep Dive**.
5. Study the ICA access-chain challenge.
6. Finish with **QDPM: Pivot from Web Login to Root** to combine web enumeration, authentication, and privilege-escalation concepts.

## How to Use the Labs

Use these labs only in authorized environments such as CTF platforms, personal virtual machines, or intentionally vulnerable training systems.

For each challenge:

1. Read the objective and confirm the authorized scope.
2. Identify relevant web applications, services, databases, or files.
3. Perform appropriate reconnaissance and enumeration.
4. Analyze credentials, configurations, encoded data, or database information.
5. Document security weaknesses and their potential impact.
6. Connect findings with defensive security controls.
7. Record lessons learned for future CTF and penetration-testing exercises.

Never test these techniques against systems without explicit authorization.
